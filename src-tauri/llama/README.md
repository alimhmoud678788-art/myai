llama.cpp Windows binaries (llama-server.exe + DLLs) are placed here by the release workflow
(.github/workflows/release.yml). They are not committed to git.

For local Windows development, download `llama-*-bin-win-cpu-x64.zip` from
https://github.com/ggml-org/llama.cpp/releases and extract its contents into this folder.
